# Market Intelligence Agent

A Java-based multi-user AI market intelligence agent developed for
EECS3311 Software Design.

## Overview

The Market Intelligence Agent combines deterministic Java components,
external financial-data services, persistent user data, and a Large
Language Model to provide natural-language financial research and
portfolio analysis.

## Planned Features

- Multi-user registration and authentication
- Persistent portfolios and watchlists
- Market quote retrieval
- Security information retrieval
- ETF sector and geographic exposure analysis
- ETF holding overlap analysis
- Security comparison
- Financial news retrieval
- Market-movement explanations
- Portfolio exposure analysis
- Persistent conversation history
- Context-aware follow-up questions
- Bloomberg-inspired terminal interface

## Technology

- Java 21
- Maven
- SQLite
- JUnit 5
- External financial-data APIs
- Large Language Model API
